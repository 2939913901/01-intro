2.2 Ingeniería de características en variables numéricas

Ahora, imputemos los datos faltantes

moda <- function(x) {
  ux <- unique(na.omit(x))
  ux[which.max(tabulate(match(x, ux)))]
}

df <- df %>%
  mutate(
    Age = ifelse(is.na(Age), median(Age, na.rm = TRUE), Age),
    `Annual Income` = ifelse(is.na(`Annual Income`), median(`Annual Income`, na.rm = TRUE), `Annual Income`),
    `Health Score` = ifelse(is.na(`Health Score`), median(`Health Score`, na.rm = TRUE), `Health Score`),
    `Number of Dependents` = ifelse(is.na(`Number of Dependents`), moda(`Number of Dependents`), `Number of Dependents`),
    `Previous Claims` = ifelse(is.na(`Previous Claims`), moda(`Previous Claims`), `Previous Claims`),
    `Vehicle Age` = ifelse(is.na(`Vehicle Age`), moda(`Vehicle Age`), `Vehicle Age`),
    `Insurance Duration` = ifelse(is.na(`Insurance Duration`), moda(`Insurance Duration`), `Insurance Duration`),
    `Credit Score` = ifelse(is.na(`Credit Score`), median(`Credit Score`, na.rm = TRUE), `Credit Score`)
  )

Para las variables numéricas continuas (Age, Annual Income, Health Score) se utilizó la mediana como método de imputación, dado que es una medida más robusta frente a valores atípicos y distribuciones sesgadas en comparación con la media. Para Number of Dependents, al tratarse de una variable de conteo (valores enteros), se empleó la moda, ya que imputar con la media generaría valores decimales sin sentido lógico para esta variable.

2.4 Ingeniería de características en variables categóricas

moda_cat <- function(x) {
  ux <- unique(na.omit(x))
  ux[which.max(tabulate(match(x, ux)))]
}

df <- df %>%
  mutate(
    `Marital Status` = ifelse(is.na(`Marital Status`), moda_cat(`Marital Status`), `Marital Status`),
    `Customer Feedback` = ifelse(is.na(`Customer Feedback`), moda_cat(`Customer Feedback`), `Customer Feedback`),
    Occupation = ifelse(is.na(Occupation), "No especificado", Occupation)
  )

Para las variables categóricas con datos faltantes se manejó cada caso según su porcentaje de NA. En Marital Status y Customer Feedback, como los faltantes eran relativamente pocos, se optó por imputar con la moda, es decir, reemplazar los NA por la categoría que más se repite. En cambio, Occupation tenía casi un 30% de datos faltantes, por lo que imputar con la moda no era buena idea (se estaría inventando la ocupación de un tercio de los clientes), así que se decidió crear una categoría nueva llamada “No especificado” para dejar claro que esa información simplemente no se tenía.

2.5 Conversión de las variables categóricas a factor

El paso siguiente es convertir las variables categóricas a factor para realizar los gráficos más facilmente.

df <- df %>%
  mutate(
    Gender = as.factor(Gender),
    `Marital Status` = as.factor(`Marital Status`),
    Occupation = as.factor(Occupation),
    Location = as.factor(Location),
    `Policy Type` = as.factor(`Policy Type`),
    `Smoking Status` = as.factor(`Smoking Status`),
    `Property Type` = as.factor(`Property Type`),
    `Education Level` = factor(`Education Level`,
                                levels = c("High School", "Bachelor's", "Master's", "PhD"),
                                ordered = TRUE),
    `Customer Feedback` = factor(`Customer Feedback`,
                                   levels = c("Poor", "Average", "Good"),
                                   ordered = TRUE),
    `Exercise Frequency` = factor(`Exercise Frequency`,
                                    levels = c("Rarely", "Monthly", "Weekly", "Daily"),
                                    ordered = TRUE)
  )

Se convirtieron todas las variables categóricas de tipo texto a factor, ya que este formato es más adecuado para el análisis en R, tanto para tablas de frecuencia como para gráficos. En el caso de Education Level, Customer Feedback y Exercise Frequency, se declararon además como factores ordenados, respetando una jerarquía lógica en sus categorías, lo que permitirá que tanto los análisis como las visualizaciones reflejen ese orden natural en lugar de mostrarlas simplemente en orden alfabético.

Para que las visualizaciones sean legibles y el documento se pueda compilar de forma eficiente, los gráficos que usan el dataset completo se generan a partir de una muestra aleatoria reproducible de 50,000 observaciones. Las tablas, estimaciones y pruebas de hipótesis continúan calculándose sobre los 1,200,000 registros.
